# Python Calculator

Консольный калькулятор с памятью и историей текущего сеанса. Небольшой проект для практики декомпозиции, обработки ошибок и автоматических тестов.

**Python 3.10+ · стандартная библиотека · pytest**

## Запуск

```sh
python -m venv .venv
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

Зависимость `pytest` нужна только для тестов; сам калькулятор использует стандартную библиотеку.

## Возможности

| Пункт меню | Действие |
| --- | --- |
| 1–4 | Сложение, вычитание, умножение, деление |
| 5–8 | M+, M−, MR, MC |
| 9 | История вычислений, включая деление на ноль |
| 0 | Завершение сеанса |

Неверный числовой ввод запрашивается повторно. Деление на ноль обрабатывается отдельно. История возвращается как копия, чтобы вызывающий код не мог изменить внутреннее состояние.

## Проверка

```sh
python -m pytest -q
```

Проверяются арифметика, память, история и CLI-сценарии с неверным вводом. «Полное покрытие» без отчёта coverage не заявляется.

```text
calculator/
  operations.py   Арифметика и DivisionByZeroError
  memory.py       Память калькулятора
  history.py      История сеанса
  cli.py          Меню и ввод
main.py           Точка входа
tests/            Регрессионные тесты
```

Ограничения: вычисления используют `float`; память и история не сохраняются между запусками. Следующий шаг — поддержка Decimal и экспорт истории.
